    2026-11-02 · Dev panel, overlay opacity and a cleaner backlog¶

    Duration: afternoon (opened on 28/10, closed today) Commits: c57ba95 — fix the dev panel · 5a3be18 — portable repo + machine rule · 4ec943e — verification lessons · 8901827 — drop the DEV tab, darker overlays · 3ca3345 — retire the finished playtests · this commit — close the session

    Objective¶

    Close what was left open on 28/10: prove the prototype works end to end, fix the dev panel that did not answer to F1, make the repo safe to work from two computers and reconcile the backlog with what has actually been played.

    What was done¶

    • Full Play mode smoke test: map → combat room → victory → reward → map, with HP, gold, deck and room counter all consistent.
    • F1 diagnosis: the code was right (Keyboard.current.f1Key inside Update); the key never arrived (the Game view did not hold focus, or the laptop sends the media key). A DEV tab was added to the canvas as a safety net.
    • The user confirmed F1 works with Fn → the tab was removed. F1, the ` key and the X button remain.
    • Machine rule for commits: tools/git-hooks/prepare-commit-msg appends Machine: <COMPUTERNAME>; installed once per clone with git config core.hooksPath tools/git-hooks.
    • Portable repo: opencode.json uses the . project path instead of the OneDrive one; .gitignore covers the Unity 6.3 *.slnx solution and .vscode/.
    • Overlay opacity: victory 0.78 → 0.95 and deck dim 0.86 → 0.97. The canvas renders in linear space, which is why the low values looked so transparent.
    • Docs: docs/index.md claimed the content lived in C#; it is CSV.
    • Backlog cleanup: the Tanda 2 playtest, the fog playtest, the content window and opencode.json are done; the radial-map numbers (24.9% dead ends, 11.35 rooms per run, last-jump edge, zoom questions) leave the list because the map is being redesigned.
    • NodeType.Elite reviewed: the generator never creates one (MapGenerator.PickType does not return it) and, if it existed, it would run a normal fight. Decision: keep it as a marker until the map redesign.

    Verification¶

    • powershell -ExecutionPolicy Bypass -File tools/compile-check.ps1 → 0 errors, 0 warnings.
    • dotnet run --project tools/content-check → 10 cards, 5 enemies, 0 relics, Content OK.
    • Play mode driven through MCP: the tab opened and closed the panel, a synthetic F1 toggled it and the X button closed it; victory with two enemies and a deck capture at 0.97; the Unity console showed no errors.
    • python -m mkdocs build clean, no broken links.

    Decisions¶

    • A test tool must not depend on a single key. The always-visible tab was tried; it was removed once F1 + Fn was confirmed, but the X button and the backtick stay because they cost nothing.
    • The machine goes in the commit automatically. A hook is deterministic; a written rule depends on whoever remembers it.
    • Raise the opacity instead of rebuilding the overlay. It is the smallest change that fixes what the eye saw and it does not touch the screen flow.
    • NodeType.Elite is neither removed nor implemented now. The map is being redesigned and the room mix will be decided again; that is when we will know whether elites belong.
    • The radial map stops being the reference. Run length will be measured on the new map (discovery radius, going back), not with LateralChance.
